# ربات تلگرام میوتونز (MeowTunes)

[English](README.md) | **فارسی**

ربات تلگرام برای [Vasl Social → MeowTunes](https://vasl.social/meowtunes): جستجوی آهنگ، آرتیست و آلبوم، دریافت فایل صوتی واقعی در تلگرام، و — پس از اتصال اکانت وصل — ارسال خودکار هر آهنگی که در میوتونز **لایک** می‌کنید.

لایهٔ API از روی نسخهٔ وب زندهٔ سایت مهندسی معکوس و روی محیط production تست شده است.

---

## امکانات

**بدون نیاز به اکانت وصل**

- جستجوی آهنگ بر اساس نام → فهرست دکمه‌ای → تحویل مستقیم فایل صوتی.
- جستجوی آرتیست → پروفایل (آهنگ‌های محبوب، آلبوم‌ها، تعداد کل آهنگ‌ها) → دانلود تک‌آهنگ.
- جستجوی آلبوم → فهرست آهنگ‌های آلبوم → دانلود یک آهنگ یا کل آلبوم به‌صورت متوالی.
- جستجوی آزاد: هر متنی بنویسید و نوع (آهنگ / آرتیست / آلبوم) را انتخاب کنید.
- ارسال صوتی بومی تلگرام (`send_audio`) همراه با `title`، `performer`، `duration` و کاور، تا آهنگ در پخش‌کنندهٔ موسیقی تلگرام دیده شود.

**نیازمند اتصال اکانت وصل**

- `/connect` → توکن `vasl_jwt_token` را از نشست مرورگر خود بفرستید. توکن در فایل SQLite محلی (با `chmod 0600`) و متصل به شناسهٔ تلگرام شما ذخیره می‌شود.
- یک watcher پس‌زمینه هر `FAV_POLL_SECONDS` (پیش‌فرض ۱۵ ثانیه) مسیر `GET /music/liked` را بررسی و آهنگ‌های تازه‌لایک‌شده را فوراً ارسال می‌کند.
- لایک‌های قبلی هنگام اتصال **بی‌صدا seed** می‌شوند تا فقط لایک‌های جدید خودکار ارسال شوند؛ `/sync` (یا دکمهٔ منو) انبار را به‌صورت دستی می‌فرستد.
- جدول `synced_favorites` (کلید ترکیبی `telegram_id + track_id`) تضمین می‌کند هیچ آهنگی دوبار ارسال نشود.
- هر آهنگ حداکثر ۳ بار برای ارسال تلاش می‌شود تا یک فایل مشکل‌دار حلقهٔ بی‌پایان نسازد.

## شروع سریع

```bash
uv venv .venv --python 3.12
. .venv/bin/activate
uv pip install -r requirements.txt

cp .env.example .env      # TELEGRAM_BOT_TOKEN را از @BotFather بگذارید
python test_vasl_api.py   # تست زندهٔ API از شبکهٔ خودتان
python main.py            # اجرای ربات (long polling)
```

بررسی توکن و API بدون اجرای ربات:

```bash
python test_vasl_api.py --token "$VASL_JWT_TOKEN"
```

اولین اجرا فایل `data/meowtunes.sqlite3` را با دسترسی `0600` می‌سازد.

### دستورها

| دستور | کار |
| --- | --- |
| `/start`, `/menu` | منوی اصلی دکمه‌ای |
| `/search [query]` | جستجو با انتخاب نوع |
| `/connect` | اتصال اکانت وصل (توکن نشست) |
| `/favorites` | مشاهدهٔ لایک‌های من |
| `/sync` | ارسال همهٔ لایک‌های ارسال‌نشده |
| `/disconnect` | قطع اتصال اکانت |
| `/status` | وضعیت ربات و اتصال |
| `/help` | راهنما |

بدون دستور هم می‌توانید مستقیم نام آهنگ/آرتیست/آلبوم را بنویسید.

## اتصال اکانت (توکن)

۱. روی دکمهٔ **«🔗 ورود به وصل»** در پیام `/connect` بزنید و در مرورگر لاگین کنید.
۲. این بوکمارکلت را یک‌بار به‌عنوان بوکمارک ذخیره کنید و روی صفحهٔ وصل بزنید تا توکن خودکار کپی شود:

```js
javascript:(()=>{const t=localStorage.getItem('vasl_jwt_token');if(!t){alert('اول وارد وصل شوید');return;}navigator.clipboard.writeText(t);alert('توکن کپی شد ✅');})()
```

۳. به ربات برگردید و توکن را بفرستید. پیام حاوی توکن بعد از ذخیره پاک می‌شود.

روش دستی: `F12` → **Application** → **Local Storage** → `https://vasl.social` → کلید `vasl_jwt_token`.

> توکن مثل رمز عبور است. آن را در هیچ جای عمومی قرار ندهید. با `/disconnect` می‌توانید پاکش کنید.

## نحوهٔ ارسال فایل صوتی

- فایل‌های تا ~۲۰ مگابایت **با URL** فرستاده می‌شوند: تلگرام خودش فایل را از CDN عمومی می‌گیرد و نیازی به آپلود از سیستم شما نیست.
- اگر ارسال با URL شکست بخورد، برای فایل‌های کوچک (≤۱۰ مگابایت) فایل آپلود می‌شود.
- فایل‌های بزرگ‌تر از ۱۰ مگابایت که URL هم برایشان کار نکند، به‌صورت **لینک دانلود مستقیم** تحویل داده می‌شوند تا ربات روی اینترنت کند قفل نشود.

## ساختار پروژه

| فایل | نقش |
| --- | --- |
| `main.py` | نقطهٔ ورود، ساخت Bot/Dispatcher و polling |
| `bot_handlers.py` | منوها، جستجو، دکمه‌ها و مسیردهی callback |
| `vasl_client.py` | کلاینت async API وصل (جستجو، آرتیست، آلبوم، مدیا، auth، favorites) |
| `media.py` | تحویل صوتی تلگرام با کاور و استراتژی URL/آپلود/لینک |
| `database.py` | SQLite: کاربران، لایک‌های sync‌شده، cache و شمارش تلاش‌ها |
| `fav_watcher.py` | پایش favorites و ارسال خودکار آهنگ‌های جدید |
| `config.py` | خواندن تنظیمات از `.env` |
| `test_vasl_api.py` | تست‌های زندهٔ API |

پوشهٔ `src/` پیاده‌سازی قدیمی TypeScript برای Cloudflare Workers است و صرفاً به‌عنوان تاریخچه نگه داشته شده؛ نسخهٔ فعال همان ربات Python است.
